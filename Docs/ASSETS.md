# Editing art and rooms

Everything in `assets/` can be edited and rebuilt with `.\build.ps1`; the Makefile notices changed files and
runs the converter (`scripts/assets.py`). If something breaks a rule below, the build stops with a message
naming the file, the frame or metatile, and the pixel position.

Placeholder art for Phase 1 was generated by a one-off script (2026-10-17). From now on **the PNGs and Tiled
files are the source**; edit them directly.

## Every graphic exists twice

The owner chose separate art per console (2026-10-17): each graphic is a pair with the **same layout**:

| File | Used by | Colours |
|---|---|---|
| `<name>.gbc.png` | `doors.gbc` | Any RGB colours, within the GBC limits below |
| `<name>.dmg.png` | `doors.gb` | Exactly the 4 DMG greys: `#FFFFFF`, `#AAAAAA`, `#555555`, `#000000` |

Sprites use transparency (alpha) for "no pixel"; backgrounds have none.

Tiled shows the `.gbc.png`. After changing it, make the matching change in the `.dmg.png` (or the DMG ROM
shows the old picture there).

## Tilesets (`assets/tilesets/`)

A tileset is a grid of **16×16 metatiles** (one DOORS "block"): `hotel.gbc.png`, `hotel.dmg.png` and
`hotel.tsx` (the Tiled tileset). The image width must stay a multiple of 16; the `.tsx` says how many columns.

Rules:

- **GBC:** at most **4 colours in each 8×8 quarter** of a metatile, and at most **8 different 4-colour
  palettes** across the whole tileset. Colours are compared at GBC precision (5 bits per channel), so two
  colours that differ only slightly count as one.
- **DMG:** only the 4 greys.
- At most 256 different 8×8 tiles per console after duplicates are removed (the hotel set uses 46) and 128
  metatiles.

Metatile properties, set in Tiled (select the tile in the tileset, Properties panel):

| Property | Type | Meaning |
|---|---|---|
| `name` | string | Becomes a constant in code, e.g. `MT_HOTEL_DOOR_TOP` |
| `solid` | bool | The player can't walk into it |

Metatile 0 must stay the **void** (solid black). It's used outside the room and for empty cells.

Current hotel metatiles: void, floor, floor_shadow (floor below a wall), carpet_l/m/r (a runner, 3 wide),
wall_top, wallpaper (upper wall face), wainscot (lower wall face), door_top/door_bottom, closet_top/
closet_bottom, dresser, table, wallpaper_shadow.

## Rooms (`assets/rooms/`)

A room is a Tiled map (`.tmx`) using one tileset:

- One tile layer, saved as **CSV** (Map → Map Properties → Tile Layer Format). Don't flip or rotate tiles.
- An object layer with a point object named **`spawn`**: the player's start (top left of the 16×16 sprite).
- Size: up to 127 metatiles per side and 3,072 in total (WRAM limit, `ROOM_MAX` in `src/room.h`).

**3/4 view convention** (how the test room is built): the top edge of a wall is `wall_top`. A wall the player
faces from below shows its face under it: `wallpaper`, then `wainscot`, then a row of `floor_shadow`. Side
walls and the bottom wall are only `wall_top`. Furniture is 1 metatile (dresser, table) or 2 tall (closet:
`closet_top` above `closet_bottom`).

To preview a room as an image: `F:\Programs\Tiled\tmxrasterizer.exe --scale 2 assets\rooms\test.tmx build\preview\test-room.png`.

## Sprites (`assets/sprites/`)

A sheet is `<name>.gbc.png`, `<name>.dmg.png` and `<name>.json`:

```json
{ "frame_width": 16, "frame_height": 16, "frames": ["down_idle", "down_a", ...] }
```

Frames are 16×16, laid out in a grid left to right, top to bottom, in the order of `frames`. Frame names
become constants (`SPR_PLAYER_DOWN_IDLE`). Each frame is drawn as two 8×16 hardware sprites, the left and
right half.

Rules:

- **GBC:** at most **3 colours** (plus transparent) in each 8×16 half, and at most 8 palettes per sheet.
- **DMG:** each 8×16 half uses either white or light grey, not both (plus dark grey and black). The hardware
  has two sprite palettes; the converter picks one per half.

The player sheet (`player`): `down_idle`, `down_a`, `down_b`, `up_idle`, `up_a`, `up_b`, `left_idle`,
`left_a`, `left_b`. There are no right-facing frames: the game mirrors the left ones. The walk cycle is idle →
a → idle → b. Colours: skin, shirt, outline/legs (GBC yellow, blue, near-black; DMG white, dark grey, black).
